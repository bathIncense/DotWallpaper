# DotWallpaper macOS P0 验证清单

> 此清单用于在真实 macOS 设备（Apple Silicon, macOS 12+）上验证 DotWallpaper 的 macOS 适配功能。

## 前置条件

- [ ] Apple Silicon Mac（M1/M2/M3/M4）
- [ ] macOS 12（Monterey）或更高版本
- [ ] 至少连接一台外接显示器（用于多显示器测试）
- [ ] 准备测试素材：
  - [ ] 静态图片（JPG/PNG/BMP/WebP/HEIC）
  - [ ] 视频文件（MP4/MOV，H.264/HEVC 编码）
  - [ ] GIF 动画（含透明、disposal 帧）
  - [ ] 动态 HEIC（solar/h24/appearance 类型各一种）

## 1. 基础功能验证

### 1.1 应用启动
- [ ] 应用能正常启动，无崩溃
- [ ] 主窗口显示正常，深色主题正确
- [ ] 菜单栏图标显示（如果有）

### 1.2 平台能力探测
- [ ] 调用 `get_platform_capabilities` 返回正确数据
- [ ] platform = "macos"
- [ ] media_kinds 包含 image/video/gif/dynamic_heic
- [ ] multi_display = true
- [ ] native_dynamic_heic = true

### 1.3 显示器枚举
- [ ] 调用 `list_displays` 返回所有连接的显示器
- [ ] 主显示器 primary = true
- [ ] 逻辑边界和缩放比正确

## 2. 静态壁纸验证

### 2.1 图片设置
- [ ] 点击壁纸图片能设为桌面壁纸
- [ ] 不同填充模式（fill/fit/stretch/center）效果正确
- [ ] 设置后系统壁纸立即更新
- [ ] 调用 `get_wallpaper_state` 返回正确状态

### 2.2 格式支持
- [ ] JPG/JPEG 图片设置成功
- [ ] PNG 图片设置成功（含透明通道）
- [ ] BMP 图片设置成功
- [ ] WebP 图片设置成功
- [ ] 静态 HEIC 图片设置成功

### 2.3 多显示器独立设置
- [ ] 可为不同显示器设置不同壁纸
- [ ] 设置一个显示器不影响另一个
- [ ] 状态显示正确

## 3. 动态壁纸验证

### 3.1 视频播放
- [ ] 选择视频文件后开始播放
- [ ] 视频循环播放，无卡顿
- [ ] 默认静音
- [ ] 暂停/恢复/停止功能正常
- [ ] 播放窗口在桌面图标之下
- [ ] 播放窗口不拦截鼠标事件
- [ ] 在所有 Space 中显示
- [ ] Mission Control 下表现正确

### 3.2 GIF 播放
- [ ] GIF 动画正确播放
- [ ] 帧时序与原文件一致
- [ ] 透明/disposal 处理正确
- [ ] 循环播放正常

### 3.3 动态 HEIC
- [ ] 动态 HEIC 能设置
- [ ] 系统动态引擎启用（时间/外观触发变化）
- [ ] 不同类型（solar/h24/appearance）行为正确
- [ ] 元数据完整保留

## 4. 生命周期验证

### 4.1 窗口管理
- [ ] 关闭管理窗口后播放继续
- [ ] 菜单栏可重新打开管理窗口
- [ ] Cmd+Q 完全退出，清理所有播放窗口

### 4.2 休眠/唤醒
- [ ] 系统休眠后唤醒，播放自动恢复
- [ ] 显示器断开后重新连接，配置恢复
- [ ] 低电量模式下可选暂停动态播放

### 4.3 热插拔
- [ ] 拔掉显示器，该显示器播放停止
- [ ] 重新插入显示器，自动恢复配置
- [ ] 镜像模式处理正确

## 5. 性能验证

### 5.1 响应时间
- [ ] 1000 张图片目录首屏可交互 ≤ 2s
- [ ] 切换壁纸响应 ≤ 500ms

### 5.2 资源占用
- [ ] 两屏 1080p30 视频连续 30 分钟不卡 UI
- [ ] 稳定期 RSS 不持续增长
- [ ] 暂停后 CPU 显著下降

## 6. 安全验证

### 6.1 权限
- [ ] 无需辅助功能权限
- [ ] 无需录屏权限
- [ ] 无需完全磁盘访问权限
- [ ] 系统壁纸数据库不被修改
- [ ] Dock 不被重启

### 6.2 沙箱
- [ ] 应用在 App Sandbox 中运行正常
- [ ] 文件访问通过系统对话框授权

## 7. 已知限制

- [ ] 动态壁纸依赖应用进程运行
- [ ] 不支持每个 Space 独立配置
- [ ] 不支持锁屏/登录屏接管
- [ ] 开机需手动启动（无自启）
